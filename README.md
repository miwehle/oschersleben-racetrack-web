# Oschersleben Racetrack – Web

Dieses Repository veröffentlicht den Browserexport der Oschersleben-Fahrsimulation.
Der bearbeitbare Projektstand und die Blender-Quelldateien liegen getrennt in einem
privaten Arbeitsrepository.

Die Simulation wird nach dem ersten Deployment unter
<https://miwehle.github.io/oschersleben-racetrack-web/> bereitgestellt.

Der Ordner `site/` wird automatisch erzeugt. Änderungen daran werden nicht von Hand
gepflegt.
